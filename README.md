# DecentraSignal

A decentralized voting and coordination platform.

## Live Demo

[Demo link]

## What it does

- Connects a user's Ethereum wallet
- Creates polls on-chain
- Records votes on-chain
- Prevents a wallet from voting twice
- Reads vote results from the blockchain

## Tech Stack

- HTML
- CSS
- JavaScript
- Solidity
- MetaMask
- Ethereum Sepolia
- ethers.js

## Important

The quadratic signaling and anti-collusion visualizations are conceptual simulations. Core poll creation and voting are handled by the deployed smart contract.
